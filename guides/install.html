全平台游戏与汉化补丁极简安装指南

三步上手，覆盖 Windows PC、安卓手机与苹果 iOS/iPad 端

电脑端 Windows 极简指南

PC
核心认知：Windows 平台运行 Ren'Py 游戏，解压路径严禁包含任何中文或特殊符号，建议统一解压至纯英文路径，杜绝底层引擎识别报错。
1
解压压缩包
下载官中原版压缩包，完全解压出来。
2
运行主程序
进入解压后的文件夹，双击 .exe 启动程序。
3
选择简体中文
进入游戏，在设置中选择简体中文即可畅玩。
避坑小贴士
官中原版无需放置任何补丁，解压即可运行。解压路径建议为纯英文。
1
解压英文原版
将下载的英文原版压缩包完全解压出来。
2
放入汉化补丁
将汉化补丁 [.rpa 文件或解压出的文件] 直接拖入 game 文件夹中。
[游戏根目录]/game/
3
启动游戏
双击运行 .exe 启动游戏，选择简体中文即可畅玩。
避坑小贴士
若读旧存档报错，请在游戏内使用坏档自愈，或备份后清空 game/saves/ 缓存重试。
1
解压 Mod
下载画廊 Mod 压缩包并解压出补丁文件。
2
放入 game 文件夹
将解压出的文件直接放入 game 文件夹中。
[游戏根目录]/game/
3
启动游戏
重新启动游戏，全 CG 解锁即时生效。
避坑小贴士
覆盖 Mod 前建议在游戏内存档备份；如需卸载 Mod，直接删除 game 目录下对应的 Mod 文件即可恢复原样。

安卓手机端 Android 极简指南

Android
核心认知：Android 11 及以上系统对系统 data 目录限制严格，落谦补丁全量适配了免系统授权的 Documents/RenPy_Saves/ 标准存储路径，安全不卡权限。
1
安装 APK
下载官中原版并安装 APK 文件。
2
放行权限
首次打开游戏，弹出存储权限提示点击允许。
3
畅玩游戏
进入游戏选择简体中文即可畅玩。
避坑小贴士
极少数附带数据包的游戏，将解压后的 game 文件夹移动到 Documents/RenPy_Saves/对应包名/game 即可。
1
安装 APK
安装游戏主体 APK，首次启动放行权限，闪退或手动大退。
2
移动文件
将英文原版 game 文件夹里的所有文件和汉化补丁 .rpa 一起移动到以下路径：
内部存储/Documents/RenPy_Saves/[对应游戏包名]/game/
3
启动游戏
重新点击游戏图标启动，选择简体中文畅玩。
避坑小贴士
请认准 Documents/RenPy_Saves/ 路径，不要移动到系统限制的 data 目录。
1
解压 Mod
下载画廊 Mod 压缩包并解压出补丁文件。
2
移动文件
将解压出的文件移动到以下路径：
内部存储/Documents/RenPy_Saves/[对应游戏包名]/game/
3
启动游戏
重新打开游戏即可生效。
避坑小贴士
覆盖 Mod 前建议在手机端提前备份存档，避免旧档冲突。

苹果移动端 iPhone / iPad 极简指南

iOS / iPadOS
核心认知：苹果 Spark 模拟器原生支持直接运行 PC 架构游戏。因此苹果玩家直接下载博文中的 PC 版压缩包 即可，无需寻找专用 iOS 包。
1
准备原版
下载 PC 官中原版压缩包 [.zip]。
2
导入模拟器
打开 Spark 模拟器导入压缩包，不用解压，不用解压，不用解压。
3
启动游戏
在模拟器内点击封面启动，选择简体中文即可。
避坑小贴士
若导入时提示空间不足，请先检查 iPhone 存储空间是否预留了游戏体积的 2 倍以上大小。
1
导入原版
将 PC 英文原版压缩包导入 Spark 模拟器，不用解压。
2
移动补丁
使用“文件”App 将汉化补丁 .rpa 移动到以下路径：
我的 iPhone/Spark/games/[对应游戏包名]/game/
3
启动游戏
在模拟器内启动游戏，选择简体中文即可。
避坑小贴士
如果在“文件”App 的 Spark 目录下没有看到对应游戏文件夹，请先在 Spark 模拟器内启动一次游戏建立目录，退出后再移动补丁。
1
解压 Mod
下载画廊 Mod 压缩包并解压出文件。
2
移动文件
使用“文件”App 将解压出的文件移动到以下路径：
我的 iPhone/Spark/games/[对应游戏包名]/game/
3
启动游戏
重新打开模拟器启动游戏即可生效。
避坑小贴士
覆盖画廊 Mod 前建议在游戏内提前备份存档；若覆盖后载入旧存档异常，可在游戏内使用坏档自愈。
