引言

近期安排

闲话少叙，简单讲一下最近以及接下来的更新安排。目前已经是 8 月中旬，距离国庆大概还有一个半月的时间。这段时间内，我会把剩下的 AI 补丁全部做完，估计还有十几个。
同时，接下来有可能会把之前一些佳作、神作的 V3 模型补丁重置一下。因为 V3 模型容易产生“幻觉”或者翻译得文绉绉的，我会直接全部替换成 V3.1 跑出来的版本，质量会大幅提升。

博客路线图（Roadmap）

补丁制作计划

遗漏补丁提醒 🔔

之前答应一些水友制作的补丁，因为时间隔得太久，我自己也快忘记了。如果你的游戏补丁还没做，或者你有想做的，都可以在 TG 群 或 博文评论区 留言提醒我。

💡 小提醒：我制作补丁不是严格按列表顺序来的，而是想到哪个做哪个，或者哪个游戏最近更新了就优先做它。所以如果没有提醒，刚好我又忘了，那这个补丁可能真的就会被彻底遗漏啦。

目前状态

依旧取消订阅制 🔓

其实从 7 月份到现在（8月中旬），我们的补丁已经一个多月没有加过订阅制了。接下来的大部分补丁，我依然不会加任何订阅限制，全部直接公开发布。
主要原因是订阅制流程太繁琐了：每次发布不仅要 Git Push 到 GitHub，还得去爱发电开赞助帖子、贴链接，一个星期后还得再手动修改博文公开…真的太占时间，而我最近工作又忙，实在抽不出空。
现在借助Codex或Antigravity等Agent智能体的辅助，翻译效率高了很多（比如最近比较棘手的某个大学生活游戏也快搞定了）。当然，制作需要精力，有条件的水友可以随缘投喂支持一下，没条件的话捧个人场也行！
8月底

🎮 Unity引擎汉化教程

原定于 5 月、后推到 7 月底的 Unity 教程，因为补丁太多和工作忙碌，一直拖到了现在。不出意外的话会在 8 月底出。
不需要任何编程基础。基本流程：安装工具 -> 配置环境 -> 调用 API（配置密钥） -> 游戏内实时翻译。我会尽量把图文教程做到通俗易懂，哪怕完全不懂代码也能照猫画虎。至于视频教程，看时间充裕度吧。虽然很少有人催更 Unity教程（毕竟受众偏少），但这手艺有就是锦上添花。
10月初

💻 Ren'Py引擎汉化教程

这个会稍微复杂点，需要一定的代码基础。不过时代变了！现在有了Codex或 Gemini这种强大的 Agent（智能体），你完全可以把我的图文教程“喂”给 AI，让它帮你写个 Skill 去自动处理。
其实主要是因为不同作者的代码习惯差异巨大，比如有些游戏逆天的存档继承机制（导致代码写法极其反人类），这些硬骨头没办法一概而论。所以这份高级教程我会放到10月之后慢慢整理，配合简润/精润的进阶思路一起讲。
10月之后

佛系更新与简润权衡 🎣

10 月之后博客会进入佛系更新状态。
后续的重心会放在简润补丁上（主要是我自己常玩的游戏）。我会用 V3 和 V3.1 模型混合打磨，因为V3.1跑出来的词汇非常接地气，虽然价格贵两倍，但“一分钱一分货”，能省下大量修 Bug 和幻觉的时间。

为什么放弃大量“精润”？ 所谓精润，是需要花大量时间去贴合角色语气、玩梗、衔接上下文的。但说实话，大部分下九流游戏作者本身也没啥文采，想把它们翻译成名著完全是做梦。与其花大量时间去精润几个冷门游戏，不如做点简润，把时间省下来出教程。毕竟，授人以鱼不如授人以渔。

关于联系方式（新增绿泡泡）

考虑到一部分水友没有注册 GitHub，无法在博客评论，又没有telegram无法进入TG群，这里特别提供一个绿泡泡（微信）联系方式。
我不怎么用 QQ（企鹅），因为它的消息经常收不到通知。绿泡泡的提醒比较及时，大家可以直接发截图反馈 Bug，或者推荐游戏。
而且对于一些需要未压缩源码的 iOS Spark 模拟器玩家，微信直接传源码压缩包也更方便，没有奇怪的审核拦截。
