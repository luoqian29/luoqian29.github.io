闲话少叙，简单说一下最近以及接下来的更新安排。距离 10 月初（也就是国庆），刚刚好还有两个半月。这段时间内我会把剩下的 AI 意译补丁全部做完，估计还有四五十个。

🗺️ 博客路线图 (Roadmap)

补丁制作计划

遗漏补丁提醒机制 🔔

之前答应一些水友制作的补丁，因为时间隔得久，我自己也快忘记了。如果你的游戏补丁还没做，或者你有想做的，都可以在 TG 群 或 GitHub 评论区 留言提醒我。

💡 小提醒：我制作补丁不是严格按列表顺序来的，想到哪个就做哪个。所以如果没有提醒，刚好我又遗漏了，那这个补丁可能真的就会被遗忘啦。

7月中旬至月底

取消强制订阅制 🔓

接下来这段时间的大部分补丁，就不再添加订阅限制了，都会直接公开发布。 主要原因是订阅制流程太繁琐：每次发布除了写文章、Push，还得去爱发电开帖子、贴链接，一个星期后还得再修改博文公开…… 真的太占时间。

当然，如果遇到极其麻烦、文本量大、耗时久的游戏，可能还是会考虑加一下订阅制。毕竟制作也需要精力，有条件的水友可以投喂支持一下，没条件捧个人场也行。

7月底

🎮 Unity 引擎汉化教程

不需要编程基础。基本流程：安装工具 -> 配置环境 -> 调用 API -> 实现游戏内实时翻译。 过程会尽量做到通俗易懂，即使完全不懂代码也能跟着图文搞定。这篇教程原本计划 5 月底就写，最近补丁太多一直没抽出空。
10月初

💻 Ren'Py 引擎汉化教程

这个会稍微复杂点，需要一定的代码基础。加上不同作者的代码习惯差异非常大，有些写法简直“反人类”，所以这部分硬骨头会放到十月之后慢慢整理。
10月之后

佛系更新与简润权衡 🎣

10 月之后的博客整体会轻松不少，更新频率会降低。 后续还是会做一些简润补丁（我自己常玩的游戏），但其他大部分游戏不会投入大量时间搞精润了。毕竟产出比例在那：打磨一个简润的时间，够做四五个 AI 意译补丁了。与其花大量时间制作少量高质量补丁，不如把汉化教程整理出来，让大家自己掌握汉化方法，授人以鱼不如授人以渔。

💬 关于联系方式 (新增绿泡泡)

考虑到一部分水友没有 GitHub 或 Telegram，这里提供一个绿泡泡联系方式。我不怎么玩企鹅（QQ），主要是企鹅信息不通知，绿泡泡提醒比较及时。毕竟我的小破站已经进小黑屋了，音符上又不能发图片，大家反馈 bug 或推荐游戏发截图，绿泡泡会方便些。
