关于博客

其实也没什么好说的，一开始我就是来发一些自己喜欢的文章而已。

因为这里不用审核嘛，我自己就是审核员，我想发什么就发什么。之前在国内发一些视频，无论是在音符还是在小破站，都会被抬走，甚至我的公众号都被封了…… 哎，太缺德了他们，我不知道谁举报的。然后现在部署在 GitHub 上，基本是没有审核啊，嘿嘿。

不知不觉，这博客就变成资源站了。妈的，一堆补丁，一堆游戏资源。虽然我自己没上传那些游戏本体（都是贴 F95，或者是从作者官网自己贴过来的），但除了一些补丁我会自己上传。原本只想发发日常，没想到搞了两三百个，累死我了。

关于订阅制

其实之前是会给一些汉化补丁加上订阅制的，一个星期后公开，费用是一个月 10 RMB。但是我不知道为什么一堆人喷我，所以我就不加了，导致现在的更新速度就变成了随缘更新：

有的话我会搬运几个官中；没的话，看到喜欢的游戏更新了，或者有水友推荐，也会顺手做一下汉化补丁。

一般我会做一些博客没有的。因为有些游戏更新了就是挤牙膏，做了也是浪费时间，还不如不做，毕竟做了还会挨骂，对吧？哈哈。

那不加订阅制之后，博客有没有收益啊？

其实收益非常少。以前不加订阅制寥寥无几，一个月就三四十块钱赞助。加了之后，最高一个月拿到过 700 多，最少也有 300 多，确实挺杯水车薪。除了大家投喂的收益，还有一个魔法推广佣金，一般也有几百块。

总之就是这样子吧，运营博客也没收多少费用，一个月跑 AI 大概就百来块，毕竟我自己也要玩一点。加上部署在 GitHub 上，费用也是挺少的，就当交点网费和电费而已~

关于资源与网盘

博客里的游戏资源本体，基本都是我从作者官网、Patreon、Itch 或者 F95 贴过来的海外网盘链接（比如 Gofile、Vikingfile、Mega 等）。有些网盘是可以裸连的（比如我在广东，基本能有个四五兆的下载速度）；但有些则过不了审，必须得挂魔法科学上网（也就是梯子/VPN）。

至于我自己上传的汉化补丁和 Mod，一般会上传到 GoFile 和 Pixeldrain 作为双重保障：

  • GoFile：部分地区（如广东）不需要科学上网就能访问。但它的机制是 7天内没人下载就会自动失效（并非资源被举报）。
  • Pixeldrain：比较稳定，但百分百需要魔法。它是只要有两个月内有人下载，文件就不会失效。基本除了官网崩掉，资源都应该在的。

为什么不像其他圈内群一样用 QQ 群文件、百度网盘或者迅雷？

一是因为我本身没有资源本体，二是因为国内审核太严，太麻烦了。用国内盘还得搞什么多次压缩、解压，乱七八糟的我不会弄，也没那闲工夫。

毕竟上面也说了，我只是简简单单为了帮助一些水友，不是“为爱发电”，不可能事事都喂到你嘴里。能用就用，用不了就算了，我也不强求，不靠这个满虚荣心。你有需要我就给，不需要就算了，就这么简单。大家看自己的需求吧。

另外，这些海外网盘不会像国内网盘那样有恶心的“会员限速”。下载速度完全取决于你的梯子质量和本地带宽（好的梯子跑到 20MB/s 也很正常）。

⚠️ 下载防坑提示：这些海外盘因为不收会员费，基本都会有广告。弹出的广告页面直接关掉就行。点击下载时，务必核对一下文件大小和文件名（一般压缩版三四个 G，原版可能十几 G），确认无误后再下，别下错成广告文件了。
